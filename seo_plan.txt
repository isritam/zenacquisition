3. TECHNICAL SEO FOUNDATION & CORE WEB VITALS
--------------------------------------------------------------------------------
A. PERFORMANCE & CORE WEB VITALS BENCHMARKS
- Largest Contentful Paint (LCP): < 1.8s
- Interaction to Next Paint (INP): < 150ms
- Cumulative Layout Shift (CLS): < 0.05

B. ASSET & CODE OPTIMIZATION RULES
1. Font Optimization:
   - Use Google Fonts with preconnect & font-display: swap.
   - Example:
     <link rel="preconnect" href="https://fonts.googleapis.com">
     <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
     <link href="https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@500;600;700&family=DM+Sans:wght@300;400;500&display=swap" rel="stylesheet">
2. Image & Media Optimization:
   - Convert all PNG/JPEG images to WebP / AVIF format.
   - Serve t1.webp - t6.webp with explicit width and height attributes to prevent CLS.
   - Implement native lazy loading for non-hero images: loading="lazy" decoding="async".
   - Hero images must include fetchpriority="high" and preloading.
3. JavaScript & CSS Bundling:
   - Production Vite JS chunks in /academy-test must be split using dynamic imports.
   - Enable Gzip / Brotli compression at the host layer.
   - Cache-Control header for static assets (/assets/*): 
     public, max-age=31536000, immutable.

9. LOCALIZED INDIAN B2B BUYING PSYCHOLOGY IN SEO COPY
--------------------------------------------------------------------------------
Standard western agency advice (Alex Hormozi / US-style cold email) often fails in India. 
The SEO content & landing page copy must directly speak to Indian agency realities:

1. WhatsApp-Native Workflows: Emphasize WhatsApp follow-ups, trust verification, and voice notes 
   over purely formal cold email sequences.
2. Vendor Skepticism & Past Betrayals: Address Indian agency owners' fear of paying monthly retainers 
   to external lead gen agencies with zero ROI. Position Zen Academy as "Ownership, Not Retainers".
3. Family & Team Financial Pressure: Frame predictable pipeline as peace of mind for payroll 
   and cashflow stability.
4. INR Pricing Transparency: State the ₹60,000 price (or ₹30,000 x 2 EMI) upfront to pre-qualify 
   organic search traffic and reduce wasted sales calls.
